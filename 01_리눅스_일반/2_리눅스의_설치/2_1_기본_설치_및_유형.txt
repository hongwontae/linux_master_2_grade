1. 리눅스 설치의 개요

    1-1. 리눅스 배포판과 설치파일의 일반적인 특징
        1. 리눅스 설치 파일은 해당 배포판의 홈페이지에서 다운로드 받을 수 있습니다.
        2. 많은 종류의 Linux OS가 존재합니다.
            => 임베디드 디바이스 리눅스, PC/노트북 같은 하드웨어에서 사용하는 리눅스..


    1-2. 설치 환경과 설치 유형
        1. 리눅스 배포판마다 설치 환경과 설치 과정이 다릅니다.
        2. 리눅스 설치 유형은 배포판마다 다르지만 패키지에 따라 데스크톱형, 서버형, 사용자 정의형으로 구분합니다.
        3. 사용자 설정 시스템이 아닌 방식으로 리눅스를 설치하면 설치 프로그램이 디스크를 알아서 파티션하면서 기존 데이터가 삭제될 수 있습니다.

        4. Minimal
            => 리눅스 설치 시 필수 패키지만 설치합니다.
        5. 데스크톱
            => 개인용 컴퓨터에 적합한 패키지를 설치합니다.
        6. 서버
            => Basic 서버 : 리눅스 서버의 필수 기본 패키지 설치
            => Database 서버 : DB 서버 관련 패키지 설치
            => Web 서버 : 아피치 웹 서버 관련 패키지 설치
        7. 랩탑
            => 노트북 등 랩탑 시스템에 적합 패키지 설치
        8. 가상 호스트 (Virtual Host)
            => 가상화 시스템 운영을 위한 패키지 설치
            => 하이퍼바이저 KVM이나 Xen을 설치
        9. Software Development Workstation
            => 소프트웨어 설치 시 필요한 다양한 도구들이 포함된 패키지 설치합니다.
            => 소스 컴파일 도구를 기본적으로 포함하기 위해 선택합니다.
            => 즉, 개발에 필요한 도구들을 한꺼번에 설치 -> gcc, gdb(디버거), make..
        10. 사용자 설정 시스템
            => 사용자 취향에 맞는 소프트웨어 선택 후 설치합니다.    


    1-3. 설치 전 준비와 주의사항
        => 설치 전 시스템에 있는 모든 파일 백업해 둡니다.
        => 멀티 부팅 시스템을 만든다면, 현재 OS 배포 미디어를 가지고 있어야 합니다.
        => 부팅 드라이브를 다시 파티션하는 경우라면, OS 부트로더를 다시 설치해야 할 수 도 있습니다.


2. 리눅스 설치를 위한 하드웨어 정보 파악

    2-1. 하드웨어 정보
        => 최근 리눅스 배포판들은 하드웨어 호환성이 우수합니다.
        => 설치 마법사의 Plug and Play 기능으로 자동으로 하드웨어를 찾아냅니다.
        => 하드디스크 드라이브 파일명 확인
            -> IDE 또는 ATA 하드디스크 타입 파일명 : /dev/hdX
            -> S-ATA, USD, SSD, SCSI 하드디스크 파일명 : /dev/sdX


3. Rocky 리눅스 설치의 실제

    3-1. Rescue a Rocky Linux System
        => 시스템이 정상 부팅이 되지 않은 경우 선택합니다.
        => 파일 시스템 손상 또는 GRUB 패스워드 분실 시 복구를 위한 선택 사항입니다.
    
    3-2. KDUMP
        => 커널 클래시 덤프 매커니즘입니다.
        => 커널 충돌이 발생 시 시스템에서 정보를 수집하여 충돌 원인을 규명하는 자료를 제공합니다.
        => 시스템 운영 중 장애를 확인하기 위해 사용하는 기능입니다.
        => KDUMP를 활성화 시 충동원인을 파악할 물리적 메모리 용량을 지정해야 합니다.


4. 리눅스 마스터 2급 문제

    4-1. 서버 유형 중 네트워크를 통해 날짜 및 시간을 동기화할 떄 사용하는 것은? 2번
        1. LDAP : TCP/IP 기반하에서 디렉터리 서비스를조회하고 수정하는 응용 프로토콜
        2. NFP
        3. NFS : 컴퓨터 사용자가 원격지 컴퓨터에 있는 파일을 마치 자신의 컴퓨터에 있는 것처럼 검색하고
            마음대로 저장하거나 수정하도록 해 주는 클라이언트/서버형 응용 프로그램
        4. kerberos : 티켓을 기반으로 동작하는 컴퓨터 네트워크 인증 암호화 프로토콜
    
    4-2. 다음 중 네트워크상에서 사용자 인증 시스템으로 적합하지 않은 것은? 3번
        1. LDAP
        2. NIS
        3. NFS : 컴퓨터 사용자가 원격지 컴퓨터에 있는 파일을 마치 자신의 컴퓨터에 있는 것처럼 검색하고
            마음대로 저장하거나 수정하도록 해 주는 클라이언트/서버형 응용 프로그램
        4. kerberos
