* 라이선스 * 
    => 프로그램을 만든 사람이 다른 사람에게 이 프로그램을 어떻게 사용해도 되는가를 정해놓은 사용 규칙입니다.
    => 프로그램을 배포하면서 몇몇 조건을 지키면 자유롭게 사용해도 된다고 정해놓인 것이 소프트웨어 라이선스입니다.

1. UNIX의 탄생과 발전

    1-1. 1960년대 후반
        => 1965년 MIT, AT&T 벨 연구소, General Electric은 시분할 OS Multics를 공동으로 개발하는 프로젝트 시작
        => 그러나 시스템이 지나치게 복잡, 개발 지연 -> 벨 연구소는 1969 철수 / Ken Thompson과 Dennis Ritchie가 Multics의 개념을 
            단순화한 UNIX 개발
    
    1-2. 1970년대
        => 1972년 벨 연구소 데니스 리치가 C언어 개발
        => 1973년 켄톰프슨과 함께 UNIX 커널을 C로 재작성
        => 이로써 UNIX는 이식성과 호환성이 뛰어난 시스템으로 발전 / 소스코드가 대학과 연구기관에 배포
        => 버클리대 BSD UNIX와 System V UNIX로 각각 발전


2. 자유 소프트웨어 운동의 등장

    2-1. 1980년대
        => 소스 코드 비공개로 전환하고 소프트웨어 상업화하는 흐름 반대 -> 리처드 스톨만
        => 리처드 스톨만이 1983년 자유 소프트웨어운동의 일환으로 GNU(GNU's Not Unix)프로젝트 시작
        => 리처드 스톨만 1985년 GNU 선언문, 자유 소프트웨어 운동을 제도적으로 지원하기 위해 비영리 단체 FSF(Free Software Foundation)설립
        ** GNU 프로젝트는 Unix와 호환되는 완전한 자유 소프트웨어 OS를 만들겠다고 선언하고 1984년 개발 시작 **
        ** GNU는 OS입니다. 다만 커널이 없었습니다. **

        => 1987년 앤드루 S. 타넨바움은 OS 교육용으로 설계된 유닉스 소형 OS인 미닉스(Minix)를 개발/공개 했습니다.
        => 미닉스는 처음에는 완전한 자유 소프트웨어나 오픈 소스 x -> 소스 코드가 교육 목적으로 공개되어 있었음
        => MINIX 3년전부터는 오픈 소스 라이선스(BSD 계열)로 전환되었습니다.
    

3. 리눅스 커널의 탄생과 성장

    3-1. 1990년대 초중반
        => GNU 프로젝트는 1980년 자체 커널인 Hurd 개발 중이었으나 완성 x
        => 1991년 리누스 토르발즈가 개발한 리눅스 커널이 1992년 GPL 라이선스를 채택하면서 GNU 도구들과 결합되어 GNU/Linux 시스템 탄생
        => 리눅스 커널은 MINIX의 커널 소스를 고쳐 GNU 시스템에 적합한 커널로 만든 것입니다.
        => 즉, 커널이 GPL 라이선스로 배포 -> GNU는 커널 없음 -> 둘이 합쳐져 GNU/Linux 시스템 탄생
