1. 디렉터리와 파일의 관리 (docker exec -it linux-study bash)

    1-1. pwd
        => 현재 작업 중인 디렉터리의 위치를 나타내는 명령어입니다.
    
    1-2. cd 경로
        => change directory의 약자, 디렉터리를 이동할 떄 사용하는 명령어입니다.
        => cd ~ : 현재 사용자의 홈 디렉터리로 이동

    1-3. mkdir [옵션] 디렉터리명
        => make directory의 약자, 새로운 디렉터리를 생성할 떄 사용하는 명령어입니다.
        => mkdir -m rwx 디렉터리명 : 디렉터리를 생성하고 권한을 설정 (defulat는 755)
        => mkdir -p : 상위 경로 생성
        => mkdir -v : 디렉터리 생성 후 생성된 디렉터리의 메시지 출력
    
    1-4. rmdir 디렉터리명
        => remove directory의 약자, 디렉터리만 삭제할 떄 사용하여 디렉터리 안에 파일이 존재하는 경우 삭제되지 않습니다.
    
    1-5. ls [옵션] [경로명]
        => 현재 위치한 디렉터리의 파일 목록들을 나타내는 명령어입니다.
    
    1-6. cp [옵션] 원본(복사할 파일 | 폴더) 대상(복사본을 만들 위치 또는 복사본의 이름)
        => 파일 또는 디렉터리를 복사하는 명령어입니다.
    
    1-7. rm [옵션] 파일명 | 디렉터리명
        => 파일 또는 디렉터리를 삭제하는 명령어입니다.
    
    1-8. mv [옵션] 원본 대상
        => 파일 또는 디렉터리를 이동하거나 파일명을 변경할 떄 사용하는 명령어입니다.
    
    1-9. touch [옵션] 파일명
        => 파일 크기가 0바이트인 빈 파일을 생성합니다.
        서버의 현재 시간으로 파일의 최근 사용한 시간과 최근 수정 시간 등 타임 스탬프를 변경합니다.
    
    1-10. file [옵션] 파일명
        => 파일의 종류 및 파일 속성값을 나타내는 명령어입니다.
    
    1-11. find [경로] [옵션] [정규표현식] [파일명]
        => 경로 주어진 조건의 파일을 찾아 해당 경로를 표시합니다.
    
    1-12. locate [파일명]
        => 파일의 위치를 찾는 명령어입니다.


2. 파일의 처리와 입출력 제어

    2-1. cat [옵션] [파일]
        => 파일의 내용을 출력하는 명령어입니다.
    
    2-2. head [옵션] 파일명
        => 파일의 앞부분을 지정한 만큼 출력하는 명령어입니다.
        => 기본적으로 파일의 앞 10줄을 출력합니다.
    
    2-3. tail [옵션] 파일명
        => 파일의 마지막 행을 기준으로 지정한 행까지의 파일 내용 일부를 출력하는 명령어입니다.
        => 기본적으로 파일의 뒷 10줄을 출력합니다.
    
    2-4. more [옵션] 파일명
        => 파일을 확인하는 명령어로 파일을 화면 단위로 끊어서 출력하는 명령어입니다.
        => 위에서 아래 방향으로만 출력되기 떄문에 지나간 내용을 다시 볼 수 없습니다.
    
    2-5. less
        => 텍스트 파일을 한 번에 한 화면씩 나타내는 명령어입니다.
        => more를 확장, 커서를 파일의 상하좌우로 이동할 수 있습니다.
    
    2-6. grep [옵션] 문자열 파일명
        => 파일에서 특정한 패턴 또는 정규 표현식으로 나타낸 단어를 찾는 명령어입니다.
        => 문자열과 정확히 일치하는 문자열만 찾는게 아니라 부분적으로 맞는 문자열도 찾습니다.
    
    2-7. wc [옵션] 파일명
        => 파일의 라인 수, 단어 수, 알파벳 수를 알려주는 명령어입니다.
        => 132 721 5230 manpath.config
        => 라인 수, 단어 수, 알파벳 수
    
    2-8. sort [옵션] 정렬할 파일명
        => 명령어 결과나 문서 내용을 정렬하는 명령어입니다.
        => 파일 내용에 영향을 주지 않습니다.
    
    2-9. cut [옵션] 파일명
        => 파일에서 특정 필드를 추출해 냅니다.
        => 필드는 구분자로 구분할 수 있습니다.
        => 필드는 구분자를 기준으로 나눈 데이터 조각입니다.
        => bb : dnjsxo / aa : wlwlwl
        => cut -d ':' -f 1 bbb.txt
    
    2-10. split [옵션] 파일명
        => 하나의 파일을 여러 개의 작은 파일로 분리할 떄 사용합니다.
    
    2-11. diff [옵션] 파일명1, 파일명2 / diff [옵션] 디렉터리1, 디렉터리2
        => 두 개의 파일을 행 단위로 비교하여 다른 부분을 출력하는 명령어입니다.
    
    2-12. cmp [옵션] 파일명1, 파일명2
        => 두 개의 파일을 바이트 단위로 비교하여 출력하는 명령어입니다.
    
    2-13. comm [옵션] 파일1, 파일2
        => 두 개의 파일을 줄 단위로 비교하여 출력하는 명령어입니다.


3. 리다이레션과 정규 표현식

    3-1. 리다이렉션
        => 표준 입력과 표준 출력의 방향을 재지정하는 것입니다.
        => 표준 입력/출력/에러가 화면이 아닌 파일로 대체됩니다. 즉, 모니터로 출력이 파일로 재지정합니다.
        => 표준 입력 장치는 키보드, 표준 출력 장치는 모니터, 표준 에러 장치는 모니터
        => 리다리렉션 -> 명령어의 입력이나 출력이 향하는 곳을 바꾸는 것입니다.
            => 리눅스 명령어는 기본적으로 세 가지 입출력 통로가 존재
            => 표준 입력 : 키보드로부터 데이터를 입력받는 통로 (키보드)
            => 표준 출력 : 정상적인 실행 결과를 내보내는 통로 (모니터)
            => 표준 에러 : 오류 메시지를 내보내는 통로 (모니터)
            => >를 사용하면 출력을 파일로 보냅니다. (파일에 저장됨)
    
    3-2. 리다이렉션 연산자
        1. >
            => 명령을 화면에 출력하는 것이 아니라 프린터나 파일에 출력하도록 전송
            => 파일이 존재하지 않으면 새로운 파일을 만들고 같은 파일이 존재하면 덮어씀
        2. >> 
            => 파일이 있는 경우 지정된 파일에 결과를 추가
            => 파일이 존재하지 않으면 지정된 이름으로 파일 생성
        3. <
            => 키보드가 아닌 지정된 파일에서 입력 내용을 읽어옴
        4. >&
            => 명령의 출력을 다른 명령의 입력으로 보냄
        5. <&
            => 명령의 입력을 읽고 다른 명령의 출력으로 보냄
    
    3-3. 파이프
        => 둘 이상의 명령을 함께 묶어 출력 결과를 다른 프로그램의 입력으로 전환하는 기능
        => 명령어와 명령어의 연결은 | 기호를 사용
        => 명령어 1 | 명령어 2 | 명령어 3
        => 명령어 1의 출력 결과는 명령어 2의 입력으로 명령어 2의 처리 결과는 명령어 3의 입력으로..
        => grep 데이터 파일 | 폴더
        => ls | grep 'txt'
        
4. 파일은 접근 시간과 수정 시간은 변경할 수 있지만 변경 시간을 변경할 수 없습니다.
    => a, m o / c x
