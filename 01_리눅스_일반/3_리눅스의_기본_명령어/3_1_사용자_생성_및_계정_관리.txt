1. 명령어와 도움말의 사용법

    1-1. which 명령어
        => 명령어의 경로를 확인하는 명령어입니다.
        => 명령어 위치를 찾아주거나 alias를 보여주는 명령어입니다. (which ll -> 구현 환경에 따라 안 보여줄 수 있습니다.)
        => $PATH가 설정되어 있는 경로에서만 해당 명령어의 경로를 찾습니다.


    1-2. alias ll = '명령어'
        => 자주 사용하는 명령어를 특정 문자로 입력해두고 명령어 대신 해당 문자를 사용할 수 있게 하는 명령어입니다.
        => alias ll='ls -l' -> ll은 ls -l
        => alias만 사용하면 alias로 등록된 모든 명령어들이 나옵니다.

    1-3. unalias alias
        => alias 기능을 해제하는 명령어입니다.
        => -a 옵션을 붙이면 모든 alias를 해제합니다.


    1-4. 환경변수 PATH
        => PATH는 실행 파일들의 디렉터리 위치를 저장해 놓은 환경 변수입니다.
        => shell은 PATH 값들을 등록해 놓습니다.
        => ls 명령어 입력 -> shell이 PATH에 등록해 놓은 경로에 따라 ls 찾기 시작 -> 찾음 -> 그 프로그램 실행
        => echo $PATH로 지정된 PATH 값을 확인할 수 있습니다.
        => PATH 추가 방법
            1. export PATH=$PATH:/home/user/mybin / $PATH는 현재 PATH 값을 가져오는 것, 거기에 덧붙이는 것입니다.
                => 이 방법은 터미널을 새로 열거나 재로그인하면 사라질 수 있습니다.
            2. ~/.bash_profile 파일에 PATH=$PATH:$HOME/mybin / export PATH 기재하면 PATH에 등록됩니다.
                => 로그인할 때 .bash_profile을 읽고 PATH에 영향을 줍니다.


    1-5. man [섹션] [옵션] 명령어
        => 리눅스에서 사용하는 명령어들의 매뉴얼을 제공합니다.
        => 매뉴얼은 9개의 섹션으로 구분되어 있습니다.
        => 같은 이름이 여러 곳에 존재할 수 있기에 섹션 번호를 통해 구분할 수 있습니다.
        => 섹션은 종류별로 명령어들을 나눈것입니다.

    1-6. info 명령어
        => 리눅스 명령어 사용방법, 옵션 등을 나타냅니다.
        => man에 비해 제공되는 명령어가 한정적입니다

    1-7. whatis 
        => 명령어에 대한 기능을 간략하게 나타냅니다.
        => 미리 만들어진 whatis DB에서 명령어를 찾아서 해당 항목을 보여주는 것입니다.
        => whatisdb -> man 페이지에서 페이지 제목과 짧은 설명을 검색하기 좋게 만들어 놓은 데이터베이스

    1-8. manpath [명령어]
        => man 페이지의 위치 경로를 검색하여 표시해주는 명령어입니다.
        => manpath는 man 페이지 경로 / manpath 명령어 -> man 페이지의 명령어가 존재하는 경로

    1-9. whereis [옵션] [명령어]
        => 찾고자 하는 명령어의 실행 파일 절대 경로와 소스코드, 설정 파일 및 매뉴얼 페이지를 찾아 출력하는 명령어입니다.

    1-10. apropos 문자열
        => man 페이지 설명에서 지정한 키워드를 포함하고 있는 명령어입니다.
        => man 페이지에 대한 검색용 데이터베이스에서 문자열을 포함한 것을 검색합니다.
        => man 페이지에 대한 검색용 데이터베이스가 만들어져 있어야 해당 명령어를 쓸 수 있습니다.
        => apropos copy -> whatis db에서 cp를 검색해 관련 명령어와 그 명령어에 대한 간단한 설명을 표시합니다.
        => 명령어 이름 자체를 모를 떄 명령어에 해당하는 키워드를 검색해서 키워드에 관련된 정보가 출력됩니다.


2. 사용자 생성 명령어

    2-1. useradd [옵션] 계정명
        => 계정을 생성하는 명령어로 명령어 adduser와 동일한 기능을 갖습니다.
        => 계정자의 홈 디렉터리는 /home/계정명
        => 생성된 계정 정보는 파일 /etc/passwd, /etc/shadow, /etc/group에 저장됩니다.
        => useradd -m /IHD 계정명은 홈 디렉터리를 IHD로 설정하는 것이지 만들어주는게 아닙니다.
        => 만약 IHD가 없다면 의미가 없습니다. -> 이 떄 useradd -m -d /IHD ihd -> 모든게 설정 완료
    
    2-2. passwd [옵션] 계정명
        => 생성된 계정자의 패스워드를 입력 및 변경하는 명령어입니다.
        => 생성된 계정자의 패스워드는 /etc/shadow 파일 안에 기록됩니다.
    
    2-3. su [옵션] [사용자] [셸변수]
        => switch user의 줄임말입니다.
        => 현재의 사용자 계정에서 로그아웃하지 않고 다른 사용자 계정으로 로그인하여 해당 사용자의 권한을 획득하는 명령어입니다.
    
    2-4. root 계정에서 다른 계정을 생성할 떄
        => useradd -m 사용자이름 (/home/사용자이름 폴더가 생기고 여기로 접속합니다.)
        => passwd 사용자이름 (비밀번호를 설정합니다.)
        => su - 사용자이름 (root에서 다른 사용자에 들어갑니다.)
    

3. 사용자 관련 파일

    3-1. /etc/default/useradd
        => useradd로 사용자 계정을 추가할 떄 사용되는 정보를 읽어오는 파일입니다.
    
    3-2. /etc/passwd
        => 계정자의 정보를 가지고 있는 파일로 리눅스에 로그인할 떄 사용됩니다.
        => 파일 내용은 여러 개의 필드로 구성되어 있으며, :으로 각각의 필드를 구분합니다.
        => username : password : uid : gid : comment : homedirectory : shell
    
    3-3. /etc/shadow
        => 계정자의 패스워드 정보가 암호화되어 있는 파일로 암호화 패스워드 및 계정의 유효 기간등을 기록하고 있는 파일입니다.
        => username : password : lastchange : mindays : maxdays : warndays : inactive : expire : flag
        => mindays -> 암호를 변경 후 사용해야 하는 최소 시간
        => maxdays -> 암호를 사용할 수 있는 최대 기간
        => warndays -> 암호가 만료되기 전에 경고를 시작하는 날수
        => inactive -> 암호가 만료된 후에도 이 항목에 지정한 날수 동안은 로그인이 가능
    
    3-4. /etc/login.defs
        => 사용자 계정 설정과 관련된 기본값을 정의한 파일입니다.
        => 새로운 계정을 생성할 떄 반드시 참조하는 파일입니다.


4. 사용자 계정 관리

    4-1. usermod [옵션] 계정명
        => 디렉터리 /home에 위치한 사용자들의 정보를 변경하는 명령어입니다.
        => 사용자의 홈 디렉터리, 그룹, 유효기간 등을 변경할 수 있습니다.
    
    4-2. userdel [옵션] 계정명
        => 기존 계정 정보를 삭제하는 명령어입니다.
        => 옵션 없이 userdel를 사용하면 디렉터리인 /etc/passwd, /etc/shadow, /etc/group에서 해당 계정의 정보가 삭제됩니다.
        => userdel -r 계정명 -> 계정명의 /var/spool/mail의 메일 파일과 홈 디렉터리의 내용을 모두 삭제
    
    4-5. chage [옵션] 계정명
        => 패스워드의 만료 정보를 변경하는 리눅스 명령어입니다.


5. 그룹 관리

    5-1. /etc/group
        => 사용자 그룹에 대해 정의되어 있는 파일입니다.
        => 모든 계정은 한 개 이상의 그룹에 포함되어 있습니다.
        => 파일 /etc/group을 이용하여 계정의 그룹에 대한 변경을 수행하거나 명령어를 이용하여 변경할 수 있습니다.
        => groupname : password : gid : members
        => password -> 그룹 비밀번호
    
    5-2. /etc/gshadow
        => 그룹의 암호를 MD5로 저장하며 그룹의 소유주, 구성원 설정이 가능합니다.
        => groupname : password : groupowner : groupmember
    
    5-3. groupadd [옵션] 명령어
        => 새로운 그룹을 생성하는 명령어입니다.
    
    5-4. groupdel 그룹명
        => 기존의 그룹을 삭제하는 명령어입니다.
        => 그룹 안에 소속되어 있는 계정명이 있을 경우 해당 그룹은 삭제되지 않습니다.
    

6. 사용자 조회 명령어

    6-1. users [옵션]
        => 시스템에 로그인한 사용자 정보를 출력하는 명령어입니다.

    6-2. who [옵션]
        => 현재 시스템에 접속해 있는 사용자들을 조회하는 명령어입니다.
        => 사용자 계정명, 터미널 정보, 접속 시간, 접속한 서버 정보 등을 확인할 수 있습니다.
        => 관리자 root와 일반 사용자 모두 사용이 가능합니다.
        => 명령어 who am i || whoami -> 자신의 정보 조회 가능
    
    6-3. w
        => 현재 접속 중인 사용자들의 정보를 나타내는 명령어입니다.
    
    6-4. id [옵션] [게정명]
        => 사용자 계정의 uid, gid, group을 확인하는 명령어입니다.
    
    6-5. groups [계정명]
        => 사용자 계정이 속한 그룹 목록을 확인하는 명령어입니다.
