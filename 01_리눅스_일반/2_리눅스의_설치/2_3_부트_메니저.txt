1. 리눅스의 부팅

    1-1. 부팅의 개념
        => 부팅은 PC의 전원을 켜는 순간부터 리눅스가 완전히 동작하여 로그인 프롬프트가 출력될 때까지를 의미합니다.
        => 리눅스 부팅 과정은 PC 부팅과 리눅스 부팅으로 나뉩니다.
    
    1-2. 리눅스의 부팅 과정
        => BIOS -> MBR -> Boot Loader(GRUB) -> Kernel -> Systemd -> Login Shell
        => BIST와 MBR은 PC 부팅이고 나머지는 리눅스 부팅입니다.

2. 바이오스 (BIOS)

    2-1. 바이오스의 개념과 특징
        => 바이오스는 컴퓨터에서 전원을 켜면 맨 처음 컴퓨터의 제어를 맡아 가장 기본적인 기능을 처리해주는 프로그램입니다.
        => ROM에 저장되어 있어 흔히 ROM-BIOS라고 합니다.
    
    2-2. 바이오스의 기능
        1. 부팅 전 하드웨어를 한번 초기화하여 사용을 준비하게 합니다.
        2. PC에 장착된 기본적인 하드웨의 상태를 확인합니다. (키보드, 마우스, 하드디스크..)
        3. 소프트웨어와 하드웨어 간의 설정 및 정보 전달의 매개 역할을 합니다.
        4. 바이오스는 하드디스크의 0번 섹터에서 MBR를 로딩하는데, MBR은 Boot Code와 Partition Table에 대한 정보를 가지고 있습니다.


3. 부트로더 (Boot Loader)
    
    3-1. 부트로더의 개념과 역할
        => 운영체제를 주기억장치에 적재하여 실행할 수 있도록 하는 프로그램입니다.
        =>운영체제가 시동되기 이전에 커널이 올바르게 구동될 수 있도록 필요한 환경을 설정하고, 운영체제 이미지를 메모리에 복사한 뒤 제어권을 커널에게 넘깁니다.
        =>부트로더는 부트 매니저라고도 하며, 하드디스크의 첫 번쨰 섹터(MBR)에 위치합니다.

    3-4. MBR (Master Boot Manager)
        => 하드디스크/SSD의 맨 앞부분에 있는 영역이며 BIOS가 운영체제를 어디서 어떻게 부팅할지 찾는 데 사용하는 정보가 있습니다.
        => MBR에는 부트 코드(부트로더를 찾아서 실행) / 파티션 테이블(디스크가 어떻게 파티션 되어 있는지) / 부트 시그니처 (유효한 부트 섹터인지)
        => MBR의 크기는 512 byte입니다. / 각 파티션에는 고유의 부트 섹터가 할당되어 부팅 프로그램을 담습니다.
        => 분할된 주 파티션은 자신만의 부트 레코드를 MBR에 등록하여 실행됩니다.
    
    3-5. 대표 부트로더
        => LILO / GRUB가 있습니다.
        => LILO는 리눅스 한정, GRUB는 리눅스 + 다른 운영체제에서 사용 가능
        => GRUB, LILO 전원 공급 -> ROM-BIOS에서 시스템 제어권을 가지고 장착된 하드웨어 점검
        => ROM-BIOS는 하드디스크 첫 번쨰 부트 섹터인 MBR에 있는 Boot Loader에게 제어권을 넘깁니다.
    
    3-6. GRUB의 개요와 특징
        => Erich Stefan Boleny에 의해서 개발되었습니다.
        => LILO의 단점을 보완한 부트로더입니다.
        => 파일 시스템과 커널 실행 포맷을 인식하여 하드디스크상에서 커널의 물리적 위치를 기록하지 않아도 
            커널 위치와 커널 이미지 파일명만 알고 있으면 부팅이 가능합니다.
    
    3-7. GRUB 환경 설정 파일
        => GRUB 1 
            -> 설정 파일 위치 : /boot/grub/menu.lst
            -> 파티션 : 첫 번쨰 파티션은 0부터 시작
            -> root 파티션 지정 방법 : root (hd0,0)
            -> 커널 이미지 설정 옵션 : kernel=옵션으로 커널 이미지 명시
        => GRUB 2
            -> 설정 파일 위치 : /boot/grub2/grub.cfg
            -> 파티션 : 첫 번째 파티션은 1부터 시작
            -> root 파티션 지정 방법 : set root=(hd0.msdos1)
            -> 커널 이미지 설정 옵션 : linux=옵션으로 커널 이미지 명시
    
    3-8. GRUB의 장치명 표기 방식
        1. GRUB에서 ROM-BIOS에서 사용하는 정보를 사용, IDE/SCSI 장치명을 별도로 구분짓지 않습니다.
            => 시스템에 정착된 순서대로 hd0, hd1..로 표기합니다.
        2. 디스크 번호와 파티션 번호는 모두 0부터 시작합니다.
        3. (디스크장치명, 파티션명) 형식으로 표기합니다.
            => (hd0,0), (hd0, 1) -> 하드디스크 첫 번쨰 첫 번째 파티션, 하드디스크 첫 번째 두 번쨰 파티션...


4. 커널 초기화

    4-1. 하드웨어 장치 초기화
        => 커널은 부팅 시 가장 먼저 메모리, 디스크, 키보드.. 장치를 검사합니다.
        => 이 과정을 통해 장치 드라이버와 자원을 초기화합니다.
    
    4-2. 커널 프로세스의 생성과 역할
        => 기본적인 초기화 과정이 끝나면 프로세스와 스레드를 생성합니다.
        => 해당 프로세스들은 메모리 관리 같은 커널의 여러 가지 동작을 수행합니다.
        => 프로세스 개수와 종류는 리눅스의 버전과 종류에 따라 다릅니다.
        => 이러한 프로세스들은 일반적인 프로세스와 구분되도록 대괄호로 표시하며, 주로 PID 번호가 낮게 배정됩니다.
    
    4-3. 커널 초기화 종료와 system 서비스 실행
        => 커널 프로세스가 생성되면 커널이 수행된 작업을 한 이후에 system 서비스를 동작시킵니다.
